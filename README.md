# Recursos dos vídeos --- Canal Saulo Oliveira

Bem-vindo(a) ao repositório de recursos do canal **Saulo Oliveira**!

Aqui você encontra os arquivos, exemplos, projetos e demais materiais
utilizados nos vídeos do canal, disponibilizados para download e para
acompanhar os conteúdos na prática.

## Organização do repositório

Os recursos estão organizados em pastas. Cada pasta leva o nome do
título do vídeo ao qual os materiais pertencem.

Assim, para encontrar os arquivos de um vídeo:

1.  Localize a pasta com o título correspondente ao vídeo.
2.  Acesse a pasta.
3.  Baixe os arquivos e utilize-os conforme demonstrado no conteúdo.
